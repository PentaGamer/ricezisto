# Issue tracker: Local Markdown

Issues, especificações e tarefas deste repositório residem como arquivos Markdown em `.scratch/` e `docs/specs/`.

## Convenções

- Uma iniciativa/feature por diretório: `.scratch/<feature-slug>/`
- A especificação principal é `.scratch/<feature-slug>/spec.md`
- Tarefas de implementação individuais residem em `.scratch/<feature-slug>/issues/<NN>-<slug>.md`, numeradas a partir de `01`
- O estado de triagem é registrado no cabeçalho de cada arquivo (`Status: <role>`)
- Discussões e observações são anexadas ao final do arquivo sob o cabeçalho `## Comments`
