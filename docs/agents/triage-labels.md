# Triage Labels

Mapeamento dos cinco papéis canônicos de triagem das skills do Matt Pocock para o issue tracker local.

| Label canônico    | Label no tracker  | Significado                                           |
| ----------------- | ----------------- | ----------------------------------------------------- |
| `needs-triage`    | `needs-triage`    | O mantenedor precisa avaliar e validar esta issue     |
| `needs-info`      | `needs-info`      | Aguardando mais informações do usuário/desenvolvedor  |
| `ready-for-agent` | `ready-for-agent` | Especificação completa, pronta para execução por IA   |
| `ready-for-human` | `ready-for-human` | Requer intervenção manual ou validação do usuário     |
| `wontfix`         | `wontfix`         | Não será implementado ou foi descartado               |
